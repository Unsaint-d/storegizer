# print-service

Компаньон-процесс для печати этикеток на NIIMBOT B1. Не содержит своего кода —
это тонкая обёртка вокруг встроенного REST-сервера пакета
[`@mmote/niimblue-node`](https://github.com/MultiMote/niimblue-node)
(бинарь `niimblue-cli`, команда `server`). Версия запинена в
[package.json](package.json) — проект в статусе Alpha, API может меняться
между версиями.

## Запуск

```bash
npm install
npm start
```

Слушает `0.0.0.0:5000` с включённым CORS (см. `scripts.start` в package.json).

## REST-контракт (из исходников niimblue-node 1.3.0)

Backend (C) обращается к этим эндпоинтам напрямую, без браузера и без
ручного клика. Все `POST`-запросы требуют `Content-Type: application/json`.

| Метод | Путь          | Тело запроса                                                                 | Назначение |
|-------|---------------|-------------------------------------------------------------------------------|------------|
| GET   | `/`           | —                                                                              | проверка живости |
| POST  | `/connect`    | `{"transport":"serial"\|"ble","address":"<путь/адрес>"}`                      | подключиться к принтеру |
| POST  | `/disconnect` | —                                                                              | отключиться |
| GET   | `/connected`  | —                                                                              | `{"connected":bool}` |
| GET   | `/info`       | —                                                                              | сведения о принтере/модели |
| GET   | `/rfid`       | —                                                                              | данные RFID-метки ленты/картриджа |
| POST  | `/print`      | `{"imageBase64"\|"imageUrl", "quantity"?, "density"?, "labelType"?, ...}`      | печать этикетки |
| POST  | `/scan`       | `{"transport":"serial"\|"ble","timeout"?}`                                    | найти доступные принтеры |

Транспорт для B1 — `"serial"` (USB-serial, путь вида `/dev/ttyUSB0` или
`COM8`), это надёжнее Bluetooth-пейринга для автоматизации, если принтер
физически воткнут в тот же сервер (см. корневой [README.md](../README.md)).

Backend должен сам вызвать `POST /connect` при старте (адрес порта —
через конфигурацию/переменную окружения, ещё не спроектировано) и затем
`POST /print` на каждую этикетку. Формат самой этикетки (какие поля
предмета/ячейки на неё попадают) не спроектирован — сюда же, в этот
контракт, ляжет и он, когда дойдёт очередь.
